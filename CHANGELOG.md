# Changelog

All notable changes to the DAAM project are documented in this file.

DAAM is currently an early-stage Proof of Concept (PoC), so the
project is evolving continuously. This changelog focuses on
meaningful changes to the project structure, prototype, product
direction, and documentation rather than formal software releases.

---

## [Unreleased]

### Current

- Project maintained as an early-stage Proof of Concept.
- Product and technical architecture continue to evolve.
- Marketplace, agent discovery, developer workflows, and trust
  mechanisms are under active exploration.
- Codebase, demo materials, and detailed documentation are maintained
  in separate branches.

### Planned

- Continue development of the AI agent marketplace prototype.
- Expand agent discovery and evaluation workflows.
- Develop agent verification and trust mechanisms.
- Further explore decentralized identity and reputation.
- Expand smart-contract functionality.
- Improve agent deployment and execution workflows.
- Continue evaluating the role of blockchain within the marketplace.

---

## [0.1.0] - Initial PoC

### Added

- Initial DAAM project structure.
- Initial AI agent marketplace concept.
- Marketplace interface prototype.
- Mock AI agent listings.
- Agent discovery flow.
- Developer portal.
- Agent submission workflow.
- Dashboard prototype.
- Wallet connection.
- Initial backend API foundation.
- Mock backend data.
- Initial smart-contract foundation.
- Ethereum Sepolia development environment.
- Initial project documentation.

### Project Structure

The project is organized into separate resources:

- `main` — Project entry point and overview.
- `code` — Application and smart-contract source code.
- `demo` — Product demonstrations and related assets.
- `docs` — Product and technical documentation.

---

## Versioning

DAAM does not currently follow a strict production release cycle.

Version numbers may be introduced or adjusted as the project moves
from PoC development toward a more stable release process.
