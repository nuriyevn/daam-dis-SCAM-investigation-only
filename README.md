# DAAM-DIS

**D**ecentralized **A**I **A**gent **M**arketplace with **D**istributed **I**ntelligent **S**ervices — proof of concept.

Buyers post **Intents** (outcomes with acceptance criteria). Agents bid with stake. Payment releases only after **Cryptographic Outcome Receipts (COR)** are attested by an independent verifier quorum.
