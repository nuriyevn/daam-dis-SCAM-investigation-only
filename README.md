# DAAM — Review Guide

**Decentralized AI Agent Marketplace** (PoC)

This branch (`main`) is the entry point. Review deliverables in this order: video → documentation → codebase.

---

## 1. Review the video

```bash
git checkout video
```

Open `daam-video.mp4` to watch the product overview.

---

## 2. Review the documentation

```bash
git checkout doc
```

Start at `docs/README.md`. It indexes the full document set (vision, architecture, PoC scope, and technical supplements).

---

## 3. Review the codebase

```bash
git checkout codebase
```

Explore the app source:

| Folder | Contents |
|--------|----------|
| `frontend/` | React UI |
| `backend/` | API server |
| `contracts/` | Smart contracts |

To run the app, follow `SETUP.md` on the `codebase` branch.

---
